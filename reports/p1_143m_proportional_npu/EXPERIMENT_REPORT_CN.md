# P1：双语数据顺序实验扩展到 143M（NPU 集群）实验报告

日期：2026-09-04 ｜ 状态：探索性扩展（exploratory scale-up），非确认性实验
前置实验：43M 初探（2080 Ti）与 43M NPU 复现，见 `../p0_43m_npu_repro/EXPERIMENT_REPORT_CN.md`

---

## 1. 实验目的

43M 初探发现：双语混训顺序对最终效果有显著影响（IID 最优、块顺序导致遗忘、中文比英文更怕忘）。本实验回答一个自然的追问：

> **这些结论在更大规模上是否依然成立，还是只是 43M 小模型的产物？**

做法是把 43M 实验"等比例放大"到 143M：模型 3.29 倍、每 run 训练 token 3.29 倍（保持 2.316 token/参数不变）、数据池 3.3 倍，其余超参数全部不动。这样 43M 和 143M 的唯一差别就是规模本身。

## 2. 实验设置

### 2.1 模型（Haidass1.5-143M 架构，Qwen3 系）

| 项 | 43M（P0） | 143M（P1） |
|---|---:|---:|
| 层数 | 12 | 30 |
| hidden / FFN | 384 / 1024 | 576 / 1536 |
| 注意力头 / KV 头 | 6 / 2 | 9 / 3 |
| head_dim / rope / eps | 64 / 1e5 / 1e-6 | 同左 |
| 词表 / 上下文 | 64000 tied / 1024 | 同左 |
| **参数量** | 43,461,504 | **143,071,296**（×3.29） |

### 2.2 训练（与 43M 逐项对齐）

- 每 run：323,584 条序列 = **331,350,016 tokens = 10,112 步**（gbs 32×1024；2.3160 tok/参数，43M 为 2.3162）
- warmup 102 步（与 43M 的 31/3072 同比例），余弦衰减到 0，peak lr 1.5e-3
- AdamW β(0.9,0.95) eps 1e-8、wd 1e-5（全参数，含 norm/embedding）、clip 2.0、fp16
- 6 条件（en_only / zh_only / iid_50 / en_first / zh_first / alternating）× 2 种子（2027/2028）= **12 个 run**
- 每 632 步存 checkpoint（17 个评测点），评测协议与 43M 完全相同：17 个 dev 点 BPB + 终点 test BPB

### 2.3 数据池（`materialized_331m_143m`）

- 每语言 337,920 条训练序列（43M 池的 3.3 倍），源配比与 43M 完全一致
- **三项验证全过**：(a) dev/test 与 43M 池逐字节一致（sha256 相同，评测集不变，跨规模可比）；(b) 每源数据块是 43M 池的前缀超集（同文档流延续）；(c) 16 源配额全部精确填满
- 未新下载任何数据——已有 50 个 shard（29GB）的余量足够（每源余量 2.7×~34×）

### 2.4 基础设施

- 容器 `mzy-mindspeed`（8 卡全挂，本实验用物理卡 4/5/6/7，0-3 留给同事）
- MindSpeed-LLM v2.3.0 + Megatron-Core 0.12.1 + torch 2.7.1 + torch_npu，CANN 环境未做任何改动
- micro batch 32、每卡 1 run（单 run 峰值显存 32.5GB；micro16 双并发实测仅快 7.6%，不冒险）
- 实测吞吐 ~0.58-0.87s/步（~40-57k tok/s/卡），单 run 约 2.2 小时，12 runs 总墙钟 ~7 小时（含评测）

## 3. 结果

### 3.1 总表（各种子均值 ± 样本标准差）

| 条件 | 指标 | 43M 初探 (2080Ti) | 43M NPU | **143M NPU** | 143M−43M |
|---|---|---:|---:|---:|---:|
| en_only | 平均测试BPB | 2.2309 | 2.2491 | **2.0412** | −0.208 |
| zh_only | 平均测试BPB | 1.8892 | 1.8920 | **1.6798** | −0.212 |
| iid_50 | 平均测试BPB | 1.6038 | 1.5962 | **1.3403** | −0.256 |
| en_first | 平均测试BPB | 1.7866 | 1.7703 | **1.5783** | −0.192 |
| zh_first | 平均测试BPB | 2.0391 | 2.0200 | **1.8820** | −0.138 |
| alternating | 平均测试BPB | 1.6925 | 1.6690 | **1.4024** | −0.267 |
| en_first | **英文遗忘** | 0.3040 | 0.3080 | **0.4568** | **+0.149** |
| zh_first | **中文遗忘** | 0.8785 | 0.8268 | **1.0912** | **+0.264** |
| alternating | 英文遗忘 | 0.0123 | 0.0129 | 0.0381 | +0.025 |
| alternating | 中文遗忘 | 0.0000 | 0.0000 | 0.0375 | +0.038 |

完整 30 行（含分语言 BPB）见 `comparison_143m.md` / `comparison_143m.json`。

### 3.2 关键发现

1. **条件排序在 143M 上完全保持**：iid_50 < alternating < en_first < zh_only < zh_first < en_only（按平均测试 BPB）。43M 的结论不是小规模的偶然。
2. **IID 依然最优**，且 alternating 相对 IID 的惩罚几乎不变：43M +4.56% → 143M +4.63%。缩短交替块有帮助、但超不过 IID 的结论在 143M 上原样成立。
3. **遗忘随规模放大**：en_first 的英文遗忘 0.308→0.457（+48%），zh_first 的中文遗忘 0.827→1.091（+32%）。模型越大、学得越好，顺序造成的遗忘反而越深——"先单语后另一语"的代价在 143M 上更严重，不是减轻。
4. **中文更怕忘的不对称性保持**：顺序遗忘量中文(1.09)仍约为英文(0.46)的 2.4 倍（43M 为 2.7 倍）。
5. **alternating 在 143M 上出现轻微中文遗忘**（0.0375，43M 时为 0）：块调度对中文的副作用在更大规模上开始显现，进一步说明块大小越均匀越好。
6. 绝对水平：143M 的 iid_50 平均 BPB 1.3403，比 43M 好 0.256（−16%），规模收益正常兑现。

## 4. 对双语训练的指导意见（143M 证据加强版）

- **全程双语交织（IID/细粒度混合）是两个规模上一致的最优策略**，优先考虑。
- **避免"先一种语言、后另一种语言"的课程式安排**；如果工程上必须分阶段，后训语言的比重应提高以补偿遗忘（且规模越大，遗忘越深，补偿要越多）。
- **中文比英文更怕忘**（两个规模、两个种子一致）：不要在训练后段把中文数据抽空；退火期尤其要保持中文占比。
- **交替块越短越好，但超不过 IID**；块调度最多作为工程折中，不作为提点手段。

## 5. 局限与下一步

- 本实验仍是探索性质：2 种子、ctx 1024、每 run 331M tokens、无下游任务评测。
- 确认性实验对应计划书 `FUTURE_EXPERIMENT_PLAN.md` 的 P2：3B tokens/run、ctx 4096、3+ 种子、下游评测、数百 GB 数据物化，是另一个量级的工程。
- 143M 与 43M 的结论一致性为 P2 提供了依据：可以预期 P2 上排序大概率保持，重点放在遗忘量与阶段配比的定量刻画。
