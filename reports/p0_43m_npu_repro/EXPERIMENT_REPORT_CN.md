# P0 43M 双语数据顺序实验 · NPU/MindSpeed 复现报告

日期：2026-09-03 ｜ 复现对象：`umeko_reports/reports/p0_scaled_100m_all_sources_2080ti/`（2080Ti 初探）

## 一、结论先说

**初探的全部定性结论在 NPU + MindSpeed 上复现成立。** 30 项对照指标（6 条件 × 5 指标，
取两种子均值）与初探的偏差全部在 ±0.052 BPB 以内，其中 27 项在 ±0.03 以内：

1. **IID 50:50 混合仍是最优双语方案**（平均测试 BPB 1.5962，初探 1.6038）；
2. **先英文后中文会遗忘英文**：英文遗忘 0.3080 ± 0.0038 BPB（初探 0.3040 ± 0.0138）；
3. **先中文后英文对中文伤害最大且不对称**：中文遗忘 0.8268 ± 0.0181 BPB（初探 0.8785 ± 0.0172）；
4. **八块交替比长块好、但不超过 IID**：交替比 IID 差 4.56%（初探差 5.53%），
   en_first/zh_first 分别差 10.91% / 26.55%（初探 11.40% / 27.14%）。

结论排序、遗忘方向、不对称性全部一致。"长语言块产生遗忘、缩短块能缓解但超不过 IID"
这一判断可以带着两个独立硬件/框架的证据进入 143M 规模实验。

## 三、复现保真度（哪些东西证明过一致）

- **数据池逐比特一致**：重新物化的 EN/ZH 训练池驱动 `make_order.py` 生成的 12 份
  schedule（条件×种子）sha256 与初探 `run_audit.json` 全部 MATCH——
  序列内容、来源配额、消费顺序三者均被证明与初探相同。
- **模型结构一致**：Megatron 侧参数量 43,461,504，与初探 HF 模型完全一致
  （12 层 / hidden 384 / FFN 1024 / 6 头 2KV / head_dim 64 / RoPE 1e5 / 词表 64000 tied）。
- **LR schedule 逐点一致**：线性 warmup 31 步 + 余弦至 0（共 3072 步）。
  注意 Megatron 在 iteration N 施加初探公式第 N−1 步的 LR（首步 lr=0、末步少一个 lr=0），
  总学习率剂量完全相同。
- **优化语义一致**：AdamW（β=0.9/0.95、eps 1e-8）、clip 2.0、global batch 32×1024。
  初探 HF AdamW 对全部参数施加 wd=1e-5；Megatron 默认排除 bias/norm，
  已用 monkeypatch 强制 `wd_mult=1.0` 作用于全部参数并单独验证。
- **评测完全一致**：`eval_bpb.py` 逐行移植初探 `evaluate()`（fp16 autocast、CE 以 fp32 求和、
  BPB=nll_sum/(bytes·ln2)、micro batch 4、dev 256/语言、test 512/语言、评测点 0/192/…/3072）。

## 四、执行环境与时耗

- 容器 `mzy-mindspeed`（与同事 verl 同镜像 `verl_pt27_25rc3:a2-arm`，只挂载物理 6/7 号 NPU，
  未安装/修改任何 CANN 组件）；torch 2.7.1 + torch_npu 2.7.1 + MindSpeed-LLM v2.3.0。
- 吞吐：单 run 单卡约 0.26 s/step（~124k tokens/s），双并发约 0.47 s/step；
  **每 run 约 24 分钟**（初探 2080Ti 约 45 分钟）。
- 12 个 run 总耗时：训练约 70 分钟（两卡 × 2 并发 × 3 波）+ 离线评测约 30 分钟，
  **端到端约 1.7 小时**（对比初探单机串行约 9 小时以上）。
- 稳定性：12 个 run 均只在第 1 步（lr=0）发生一次 overflow skip，无实际影响；
  loss scale 最低 4096（2 的幂次调整，对梯度数值无影响）；最终训练 loss 3.70~4.88。

## 五、已知偏差（诚实声明）

1. **初始权重不逐比特一致**：初探初始化在 Windows 平台生成，`std::normal_distribution`
   的平台差异导致同种子不同值；已排除 torch/transformers 版本因素。本次同一 seed 下
   6 个条件共享同一初始化，内部对照完整。
2. **micro batch 4×累加8 → 32×1**：global batch 不变，数学等价，仅 fp32 梯度求和顺序不同；
   smoke 对比前 64 步 loss 偏差 ~1e-3。
3. **融合算子**：flash-attn / fused-rmsnorm / fused-swiglu 与初探朴素实现有微小数值差。
4. **fp16 loss scale 轨迹不同**：初探全程 65536，NPU 侧早期降至 4096~32768 不等。
5. **硬件/框架差异**：CUDA/2080Ti vs CANN/910B3，底层 kernel 实现不同。
