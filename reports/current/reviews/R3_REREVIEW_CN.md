## 已实际解决的问题

1. **未完成贡献与占位结果已撤回。** 标题和摘要现在围绕数据选择与语言顺序；M:L47–62 的贡献只列已完成经验研究与复现记录，并明确不声称最佳比例、正迁移或 scaling law。M:L278–279 明说 q=.25/.75 和等曝光分解未完成；未来分解放到 M:L396–406，并指出数据前缀和优化历史不匹配。与首轮相比，这项拒稿理由已实际消除。既然范围已改变，我不会继续以“没有完成原计划比例扫描”作为当前稿必须补实验的要求。

2. **实际运行设置不再与未来方案混写。** M:L106–137 给出 24 个已完成运行和真实的 ctx1024、global batch32、3,072/10,112 更新、FP16 与 token 预算。M:L146–151 正确定义固定语言配额的随机排列，并承认顺序、近期语言曝光和学习率位置共同变化。这修复了首轮关于“读者可能把正式计划的配置误认为已执行配置”的主要问题。

3. **历史损失已被正确命名和限定。** M:L159–178 解释 1023 个预测位置与整块解码 bytes 的不一致、EOS 边界约定、256/512 个 dev/test 块及 SD 口径；已有图的 BPB 标签也在 M:L259–262 的图注中解释为历史量。对同语言、同 eval，若只更正所有条件共同的字节分母，相对 IID 比值确实抵消该分母。这一代数事实支持保留已有相对损失比较，而不是宣称已完成实验无效。作者没有宣称改变 EOS 或预测边界后的分子也必然保序；M:L274–277 还撤回“中文本质更易遗忘”的推断。

4. **中文表是实际加入的已有结果。** M:L289–314 新增发布 checkpoint 的 349/1346、2949/11582、289/500、300/504，分别为 25.93%、25.46%、57.80%、59.52%。我此前已逐项审计 121 个文件、13,932 条保存预测，汇总和 argmax 一致。表注明确 BF16、零样本、前两项按题加权、任务自身似然协议、扩展 XWinograd/CLUE 来源和污染状态未知；正文明确考试型任务接近随机。首轮“发布模型中文结果未在稿中报告”的缺口已解决。它们是发布模型表现，**没有被误当成 IID 与分块训练的因果对照**；相应的受控双语下游缺口仍在。

5. **未来评估与 2×2 的识别对象已修正。** M:L376–379 不再假设 XCOPA 有直接英文配置，要求 COPA/XCOPA ID 和标签对齐。M:L381–394 的四格现在明确只识别英文过滤×中文过滤的效应，固定 IID 不用于识别质量×顺序交互；旧五源 IID 不能替代新 web-only Q0。这解决了设计逻辑错误，但四格仍未执行，我不给它任何结果分。

## 承认了但尚未解决的问题

1. **受控顺序研究尚缺任务表现的连接。** M:L286–287 仍说明受控模型没有完成成对中英下游评估；发布版中文表来自不同训练历史，不能补足这条连接。现有结果能支持“同一 held-out 语料与历史度量下，随机混合优于所测试长块方案”，不能保证其阅读理解、常识判断或双语同时正确率也按同一顺序排列。无需新训练就有可能通过已有 checkpoint 的冻结评估加强这一点，因而这是我仍最关注的可行补证据方向。

2. **度量解释已修复，规范度量重评尚未完成。** 共同分母的抵消不解决首 token/EOS 评分约定改变分子的可能性，也不能从 packed sequence 汇总恢复独立逐文档不确定性。相同语料上的大幅相对差异仍是有意义的探索发现；但精确效果值和“尺度收益保留比例”的解释仍依赖历史协议。本轮应评价作者现在披露的真实指标，不能将其自动升级为已完成的标准逐文档 BPB 确认研究。

3. **新的科学信息仍偏有限，范围收束并不等于完成实验连接。** 五档约 20B-token 的英文扫描是重要既有实验；两个双语规模的 24-run 比较也提供独立方向的信息。当前稿还公开了 143M 在不同聚合下可由正转负的敏感性（M:L221–226），提升了可信度。但两部分分别改变英文质量与双语顺序，没有在同一受控设置中检验质量如何改变双语训练结论。新题名不再承诺已验证联合配方，所以我不把四格缺失视为违约；我的保留是当前两组结果提供的新认识和普遍适用范围仍较窄，而不是“实验没做够大”。已知的长块遗忘现象、两个同时改变模型与 token 的尺度点和有限外部任务连接，尚未形成很强的解释或新结论。

4. **复现与污染仍是实质限制。** 现有配置、哈希和逐题结果使工作可追踪；英文历史单次训练和数据曝光记录、双语校正后的逐文档记录、发布模型完整污染状态仍缺。中文成绩有内部一致性证据，但模型仓库 revision、历史 loader revision 和完整代码快照并非同一层次的锁定。M:L322–328、351–356 如实披露了这些限制；这种披露解决了夸大，尚未补齐缺失工件。我不会把 checkpoint 数或题目 bootstrap 当作新增训练种子，也不会因无法补昂贵 seed 而否认已经完成的运行。

## Questions / 对下一步的限定

若还安排一项低成本补证据，我优先考虑已有受控 43M/143M checkpoint 上的小型、预先固定的中英下游与规范文本损失重评，完整报告未超过随机或排序不一致的结果。它直接检验当前主文顺序结论能延伸到哪里；不需要重复训练既有 24 个运行。

若现有 checkpoint 暂不可取得，作者可维持当前探索性定位，不应以一个未来四格计划填补结果。固定 IID 的英文质量×中文质量设计是一条合理的新研究路线，但它的预计八个 run、适配器或预算表均不计入本轮推荐。本文也不要求恢复已延期的大规模三种子矩阵。

## Recommendation

**4／10：略拒；首轮为 2／10。** 提分依据是实际稿件已撤回未完成核心承诺，准确交代已完成的两组规模实验，修复历史损失解释，并加入经逐题核验的发布模型中文表。这些变化让论文从证据错位的未完成配方叙事，变成可以按真实探索结果讨论的经验研究。
